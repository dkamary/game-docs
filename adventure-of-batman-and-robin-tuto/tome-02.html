Chapitre 1

Le Système Balistique

Instanciation de projectiles et l'erreur de débutant à éviter.

L'Erreur Classique : Le Batarang Enfant

L'erreur la plus commune sur Godot est de faire `add_child(batarang)` directement dans le script du `Player`. Pourquoi est-ce une erreur ? Parce que si le projectile est un enfant du joueur, ses coordonnées sont relatives au joueur. Si Batman recule, le projectile en l'air reculera avec lui ! Il faut ajouter le projectile à l'arbre principal (la scène courante).

Simulation de Tir (Indépendant)

1. La Scène Batarang.tscn

Le Batarang est simplement un Area2D. Grâce à notre architecture du Tome 1, il agit comme un HitboxComponent volant.

Arbre de Nœuds (Batarang)

  • Batarang (Area2D / HitboxComponent)
  • Sprite2D
  • CollisionShape2D
  • VisibleOnScreenNotifier2D

Le Noeud Secret : VisibleOnScreenNotifier2D

Si vous tirez 500 batarangs et qu'ils sortent de l'écran, ils continuent de consommer de la mémoire. Le VisibleOnScreenNotifier2D émet un signal screen_exited. Connectez-le pour détruire (queue_free()) le projectile dès qu'il sort de l'écran !

2. Script du Batarang (batarang.gd)

# batarang.gd (Hérite de notre HitboxComponent du Tome 1 !)
extends HitboxComponent

@export var speed: float = 600.0
var direction: Vector2 = Vector2.RIGHT

func _physics_process(delta: float):
    # Déplacement linéaire simple
    position += direction * speed * delta
    # Rotation infinie pour l'animation (en radians)
    rotation += 15.0 * delta

# Connecté via l'éditeur depuis le VisibleOnScreenNotifier2D
func _on_visible_on_screen_notifier_2d_screen_exited():
    queue_free()

# Connecté via l'éditeur depuis le signal area_entered de l'Area2D
func _on_area_entered(area: Area2D):
    # Si on touche une Hurtbox ennemie (la logique de dégât est dans le Tome 1)
    if area is HurtboxComponent:
        queue_free() # Le batarang se détruit après impact

3. Tirer depuis le Player (player.gd)

# Dans player.gd
@export var batarang_scene: PackedScene
@onready var muzzle = $Muzzle # Un Node2D (Marker2D) placé au bout du bras de Batman

func shoot_batarang():
    if batarang_scene:
        var projectile = batarang_scene.instantiate()
        
        # IMPORTANT : On ajoute le projectile à la racine de la scène, pas au joueur !
        get_tree().current_scene.add_child(projectile)
        
        # On place le batarang au niveau du canon (muzzle)
        projectile.global_position = muzzle.global_position
        
        # On définit la direction basée sur l'orientation de Batman
        if $Sprite2D.flip_h:
            projectile.direction = Vector2.LEFT
        else:
            projectile.direction = Vector2.RIGHT
Chapitre 2

Les Sbires du Joker

Donner vie aux ennemis via une State Machine simplifiée.

Les clowns dans Batman & Robin ont un comportement précis : ils patrouillent ou attendent, puis dès que Batman entre dans leur champ de vision, ils foncent vers lui. S'ils le touchent, ils explosent de rire. Nous allons utiliser un RayCast2D pour la vision.

Simulation RayCast (Vision)

Status: Idle (En attente)

Structure de l'Ennemi (Clown.tscn)

L'ennemi est aussi un CharacterBody2D (pour subir la gravité). Il possède un HurtboxComponent pour recevoir les Batarangs, et un HitboxComponent sur son corps pour blesser Batman s'il le touche.

# clown_ai.gd
extends CharacterBody2D

const SPEED = 120.0
var gravity = ProjectSettings.get_setting("physics/2d/default_gravity")
var state = "IDLE" # États simples : IDLE, CHASE, HURT

@onready var vision_cast = $RayCast2D # Pointeur vers l'avant (axe X)
@onready var sprite = $Sprite2D
@onready var hurtbox = $HurtboxComponent

var player_ref = null

func _ready():
    # On connecte le signal de notre composant Hurtbox créé au Tome 1 !
    hurtbox.on_damage_taken.connect(_on_damage_taken)

func _physics_process(delta: float):
    if not is_on_floor():
        velocity.y += gravity * delta

    match state:
        "IDLE":
            velocity.x = 0
            # Vérifie si le Raycast touche un corps appartenant au joueur
            if vision_cast.is_colliding():
                var collider = vision_cast.get_collider()
                if collider.is_in_group("Player"):
                    player_ref = collider
                    state = "CHASE"
                    
        "CHASE":
            if player_ref != null:
                # Calcule la direction vers le joueur (1 ou -1)
                var direction = sign(player_ref.global_position.x - global_position.x)
                velocity.x = direction * SPEED
                
                # Tourne le sprite et le Raycast en fonction de la direction
                sprite.flip_h = direction > 0
                vision_cast.target_position.x = abs(vision_cast.target_position.x) * direction
                
        "HURT":
            velocity.x = move_toward(velocity.x, 0, SPEED * 0.1) # Recul (Knockback)

    move_and_slide()

func _on_damage_taken(damage_amount: int):
    state = "HURT"
    # Ajouter ici la logique de clignotement ou de mort...

Chapitre 3

Créer Gotham City

Profondeur de champ Megadrive et le nouveau TileMapLayer (Godot 4.3).

L'esthétique de Batman & Robin repose sur son "Parallax Scrolling" : des couches d'arrière-plan qui défilent à des vitesses différentes pour simuler la 3D. Godot gère cela nativement.

Aperçu du Rendu (3 couches)

Structure du Noeud ParallaxBackground

  • ParallaxBackground
  • ParallaxLayer (Ciel)
    Motion Scale: x=0.0, y=0.1
  • ParallaxLayer (Ville Lointaine)
    Motion Scale: x=0.3, y=0.5
  • ParallaxLayer (Immeubles Proches)
    Motion Scale: x=0.7, y=0.8

Le Secret du Mirroring

Pour que la ville boucle infiniment, sélectionnez un ParallaxLayer. Dans l'inspecteur, sous Motion > Mirroring, entrez la largeur exacte de votre texture (ex: 320 ou 640).

Nouveauté Godot 4.3+ : TileMapLayer

Fini l'ancien nœud TileMap géant qui gérait tout. Godot 4.3 introduit TileMapLayer. C'est plus propre et plus modulaire. Vous mettez un TileMapLayer pour le décor de fond, un autre pour les plateformes (avec collisions), etc.

Comment ajouter des collisions au sol ?

  1. Dans le panneau du bas (TileSet), sélectionnez vos tuiles de sol.
  2. Allez dans l'onglet Paint.
  3. Choisissez Physics Layer 0.
  4. Dessinez un rectangle sur votre tuile. Magie : Batman ne passera plus à travers le sol !
Chapitre 4

Le "Juice" : FX & Audio

Ce qui transforme un prototype en jeu fini.

Sur Megadrive, les explosions sont généralement de simples Sprite Sheets (feuilles de sprites) jouées rapidement, parfois accompagnées de particules simples. Nous allons utiliser un AnimatedSprite2D instancié dynamiquement au point d'impact.

Créer une Explosion Automatisée

Créez une scène `Explosion.tscn` avec comme racine un `AnimatedSprite2D`. Chargez-y vos frames d'explosion. Le but est qu'elle se détruise toute seule une fois l'animation terminée.

# explosion.gd (Attaché à l'AnimatedSprite2D)
extends AnimatedSprite2D

func _ready():
    # Connecte le signal "animation_finished" à queue_free
    animation_finished.connect(queue_free)
    
    # Lance l'animation par défaut
    play("default")

# Optionnel : Ajouter un AudioStreamPlayer enfant et le jouer ici
# $AudioStreamPlayer.play()
