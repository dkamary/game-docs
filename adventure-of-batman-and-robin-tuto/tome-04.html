Chapitre 1

L'Esthétique 16-Bits (Shaders)

Émuler les écrans cathodiques avec les Shaders Godot.

Le Pixel Art n'était pas "carré"

Le pixel art de la Megadrive a été dessiné pour être affiché sur des écrans CRT (à tube cathodique). Ces écrans "bavaient", mélangeaient les couleurs et avaient des lignes de balayage (scanlines). Un jeu rétro affiché sur un écran LCD 4K moderne parait souvent "trop net".

Simulation Filtre CRT (CSS)

Implémentation Godot (CanvasLayer)

Pour appliquer un effet sur tout l'écran, créez un CanvasLayer avec un ColorRect qui recouvre tout l'écran. Dans la propriété Material du ColorRect, créez un nouveau ShaderMaterial.

// crt_effect.gdshader
shader_type canvas_item;

// Récupère l'image rendue en dessous de ce noeud
uniform sampler2D screen_texture : hint_screen_texture, repeat_disable, filter_nearest;

uniform float scanline_intensity : hint_range(0.0, 1.0) = 0.2;
uniform float color_bleeding : hint_range(0.0, 5.0) = 1.2; // Aberration chromatique

void fragment() {
    vec2 uv = SCREEN_UV;
    
    // 1. Aberration Chromatique (Décalage du Rouge et Bleu)
    float r = texture(screen_texture, uv + vec2(color_bleeding * SCREEN_PIXEL_SIZE.x, 0.0)).r;
    float g = texture(screen_texture, uv).g;
    float b = texture(screen_texture, uv - vec2(color_bleeding * SCREEN_PIXEL_SIZE.x, 0.0)).b;
    
    vec3 color = vec3(r, g, b);
    
    // 2. Scanlines (Lignes sombres horizontales basées sur les UV Y)
    // Multiplie par la résolution verticale (ex: 224 pour la Megadrive)
    float scanline = sin(uv.y * 224.0 * 3.14159); 
    if (scanline > 0.0) {
        color -= scanline_intensity;
    }
    
    COLOR = vec4(color, 1.0);
}
Chapitre 2

Performance : Object Pooling

Arrêtez de créer et détruire, commencez à recycler.

Dans Godot, instantiate() (Créer) et queue_free() (Détruire) coûtent cher en mémoire. Si Batman tire 10 batarangs par seconde, le Garbage Collector (nettoyeur de mémoire) va provoquer des micro-saccades (stutters).
La solution des pros : créer 20 batarangs au lancement du niveau, les cacher, et les réutiliser en boucle.

Le Script ProjectilePool.gd (Autoload)

Ce script doit être un Singleton (Autoload) ou placé au sommet de votre scène principale. Il gère un tableau (Array) de Batarangs "endormis".

# projectile_pool.gd
extends Node

@export var projectile_scene: PackedScene
var pool: Array = []
const POOL_SIZE = 20

func _ready():
    # 1. Instancier tout au début du jeu (chargement)
    for i in POOL_SIZE:
        var proj = projectile_scene.instantiate()
        proj.hide() # Invisible
        proj.set_process(false) # Désactive la physique
        proj.set_physics_process(false)
        
        # IMPORTANT: On connecte un signal perso "died" au lieu d'utiliser queue_free
        proj.died.connect(_on_projectile_died.bind(proj))
        
        add_child(proj) # Reste dans l'arbre
        pool.append(proj)

func get_projectile() -> Node2D:
    if pool.size() > 0:
        var proj = pool.pop_back() # Retire du tableau des objets dispo
        proj.show()
        proj.set_process(true)
        proj.set_physics_process(true)
        return proj
    return null # Plus de munitions dans le pool !

# Quand le batarang touche un mur ou sort de l'écran, il appelle proj.died.emit() 
# AU LIEU de queue_free(). On le remet dans le pool.
func _on_projectile_died(proj):
    proj.hide()
    proj.set_process(false)
    proj.set_physics_process(false)
    pool.append(proj) # Retourne dans l'inventaire invisible
Chapitre 3

Mixage Audio : Le Secret du Ducking

Faire de la place pour les explosions sans couper la musique.

Avez-vous remarqué comment, dans les jeux d'action modernes, la musique de fond baisse légèrement de volume juste au moment d'une grosse explosion pour laisser la place au son, puis remonte ? C'est ce qu'on appelle le Sidechain Ducking ou Audio Ducking. Godot 4 gère cela nativement via les Bus Audio.

Configuration dans l'Éditeur Godot

  1. Ouvrez le panneau Audio en bas de l'éditeur Godot.
  2. Créez deux nouveaux Bus en plus du bus Master : nommez-les Music et SFX (Sound Effects).
  3. Sur le bus Music, ajoutez un effet Compressor.
  4. Dans les paramètres de cet effet Compressor, activez Sidechain et sélectionnez le bus SFX.
Que se passe-t-il ? Chaque fois qu'un son joue sur le bus SFX (ex: $AudioStreamPlayer.bus = "SFX" pour l'explosion), le compresseur du bus Music va "écraser" le volume de la musique proportionnellement à l'intensité de l'explosion. C'est automatique et ça donne un mixage digne d'un studio !

Le SceneManager (Autoload)

Créez une scène SceneManager.tscn avec un CanvasLayer, un ColorRect noir couvrant tout l'écran (opacité 0), un AnimationPlayer (qui anime l'opacité du noir) et ajoutez cette scène dans les Autoloads du projet.

# scene_manager.gd (Autoload)
extends CanvasLayer

@onready var anim = $AnimationPlayer
@onready var color_rect = $ColorRect

# Fonction globale appelable de partout : SceneManager.change_scene("res://boss.tscn")
func change_scene(target_path: String):
    # 1. Bloquer les inputs du joueur pendant la transition
    get_tree().get_root().set_disable_input(true)
    
    # 2. Jouer l'animation de Fondu au Noir (opacité 0 à 1)
    anim.play("fade_to_black")
    await anim.animation_finished
    
    # 3. Changer la scène (Pendant que l'écran est noir)
    get_tree().change_scene_to_file(target_path)
    
    # 4. Jouer l'animation d'ouverture (opacité 1 à 0)
    anim.play("fade_to_normal")
    await anim.animation_finished
    
    # 5. Rendre le contrôle au joueur
    get_tree().get_root().set_disable_input(false)
