Chapitre 1

Multijoueur : "Player 1 & 2"

Un seul script pour les gouverner tous.

L'Erreur à éviter

L'erreur classique pour ajouter Robin est de copier la scène player.tscn, de la renommer player2.tscn et de dupliquer tous les scripts. C'est une abomination en termes de maintenance (si vous corrigez un bug pour Batman, vous devez le refaire pour Robin).
La solution : L'Interpolation de chaîne de caractères dans les Inputs !

1. Map des Inputs

Dans Projet > Paramètres du projet > Contrôles, vous devez structurer vos actions de cette manière :

  • p1_move_left (Q / Joy-Con 1)
  • p1_jump (Espace)
  • p2_move_left (Flèche Gauche)
  • p2_jump (Entrée)

2. L'Adaptation (player.gd)

# player.gd
extends CharacterBody2D

# 1 = Batman (Manette 1), 2 = Robin (Manette 2)
@export var player_id: int = 1 

func _physics_process(delta):
    # Construit le nom de l'action dynamiquement avec %s
    var left = "p%s_move_left" % player_id
    var right = "p%s_move_right" % player_id
    var jump = "p%s_jump" % player_id
    
    # Utilisation de l'action calculée
    if Input.is_action_just_pressed(jump):
        velocity.y = -400
        
    var dir = Input.get_axis(left, right)
    velocity.x = dir * 150.0

La Caméra Partagée

Garder les deux héros à l'écran coûte que coûte.

Si Batman part à droite et Robin à gauche, une Camera2D classique attachée à Batman va sortir Robin de l'écran. Nous devons détacher la caméra des joueurs, la placer à la racine de la scène, et utiliser les mathématiques pour cibler **le point central entre les deux joueurs**.

Le Script CoopCamera.gd

Ce script se place sur un nœud Camera2D autonome. Il cherche tous les nœuds dans le groupe "Players", additionne leurs positions et divise par le nombre de joueurs.

# coop_camera.gd
extends Camera2D

@export var max_zoom: float = 1.5
@export var min_zoom: float = 0.8

func _process(delta):
    # Récupère le tableau de tous les joueurs (Batman, Robin)
    var players = get_tree().get_nodes_in_group("Players")
    if players.size() == 0:
        return
        
    # 1. Calculer le point central (Barycentre)
    var center_pos = Vector2.ZERO
    for p in players:
        center_pos += p.global_position
    center_pos /= players.size()
    
    # Lerp pour un mouvement de caméra doux
    global_position = global_position.lerp(center_pos, 5.0 * delta)
    
    # 2. Calculer l'écart maximal (Distance entre les joueurs)
    if players.size() > 1:
        var distance = players[0].global_position.distance_to(players[1].global_position)
        
        # Ajuster le zoom : Plus ils s'éloignent, plus on dézoome (chiffre petit)
        # (Basé sur la taille de l'écran, ex: 320px)
        var target_zoom = clamp(320.0 / (distance + 50), min_zoom, max_zoom)
        zoom = zoom.lerp(Vector2(target_zoom, target_zoom), 2.0 * delta)

L'Astuce Godot 4 : Le SubViewport

Plutôt que d'écrire un Shader mathématique complexe pour tordre un `Sprite2D`, Godot nous permet d'afficher une scène 2D à l'intérieur d'un monde 3D, puis de filmer ce monde 3D.

  1. Créez un SubViewportContainer (Taille : 320x224).
  2. Ajoutez-lui un SubViewport en enfant.
  3. Dans ce SubViewport, créez une scène Node3D !
  4. Ajoutez une Camera3D (Angle X: -45°, reculée vers le haut).
  5. Ajoutez un MeshInstance3D (Type : Plane).
  6. Sur le matériau du Plane, mettez votre texture de sol, activez Unshaded, et faites tourner le Plane en code (rotation.y += delta).
  7. Résultat : Le SubViewport 2D affichera votre sol rotatif parfait en arrière-plan de votre jeu 2D !
Chapitre 4

Score Arcade & Combos

Donner un sens à l'action frénétique.

Un Run & Gun ne serait rien sans le score. Mais pour encourager le beau jeu, nous allons implémenter un multiplicateur de combos qui retombe à zéro si le joueur ne tape rien pendant 3 secondes.

Le ScoreManager (Autoload)

# score_manager.gd (Autoload)
extends Node

signal score_updated(new_score)
signal combo_updated(new_combo)

var score: int = 0
var combo_multiplier: int = 1

@onready var combo_timer = Timer.new()

func _ready():
    add_child(combo_timer)
    combo_timer.wait_time = 3.0 # 3 secondes pour enchaîner
    combo_timer.one_shot = true
    combo_timer.timeout.connect(reset_combo)

func add_points(base_points: int):
    score += base_points * combo_multiplier
    combo_multiplier += 1
    
    score_updated.emit(score)
    combo_updated.emit(combo_multiplier)
    
    # Relance le timer (remet à zéro le décompte des 3 sec)
    combo_timer.start()

func reset_combo():
    combo_multiplier = 1
    combo_updated.emit(combo_multiplier)
