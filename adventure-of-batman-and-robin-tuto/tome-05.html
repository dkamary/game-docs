Chapitre 1

Dompter les Control Nodes

Finis les boutons placés au pixel près qui cassent selon l'écran.

Le Système d'Ancrage de Godot

L'erreur classique des débutants est de placer un bouton sur l'écran et de glisser ses coordonnées (X, Y). Si la résolution change, le bouton est hors de l'écran. Dans Godot, tout ce qui est UI doit hériter de Control (les icônes vertes), et on utilise les conteneurs (Containers) pour organiser l'espace.

Arbre Nœuds : Menu Principal

  • MainMenu (Control)
  • TextureRect (Background)
    Ancrage: Full Rect
  • MarginContainer
    Ancrage: Full Rect. Marges: 40px
  • VBoxContainer (Align: Bottom)
  • Button (Start)
  • Button (Options)
  • Button (Quit)

MarginContainer

Définit des marges de sécurité invisibles autour de l'écran pour éviter que les textes ne touchent les bords sur les téléviseurs (Safe Zone).

VBoxContainer

Empile automatiquement ses enfants (les boutons) verticalement. Plus besoin de calculer l'espacement Y entre chaque bouton !

Chapitre 2

Navigation à la Manette (Focus)

Parce qu'on ne joue pas à la Megadrive avec une souris.

Par défaut, les boutons Godot réagissent au clic de la souris. Pour naviguer à la manette (D-Pad), il faut utiliser le système de Focus. Godot calcule automatiquement quel bouton est en haut, en bas, à gauche ou à droite d'un autre (Focus Neighbors).

Le Code Indispensable (main_menu.gd)

Pour que la navigation clavier/manette fonctionne, un élément de l'UI doit avoir le focus dès l'ouverture de la scène.

# main_menu.gd
extends Control

@onready var start_button = $MarginContainer/VBoxContainer/StartButton
@onready var quit_button = $MarginContainer/VBoxContainer/QuitButton

func _ready():
    # CRUCIAL : Donne le focus au bouton "Start" au lancement
    start_button.grab_focus()
    
    # Connexion des signaux 'pressed' (qui réagissent aussi à la touche 'ui_accept' / Croix Manette)
    start_button.pressed.connect(_on_start_pressed)
    quit_button.pressed.connect(get_tree().quit)

func _on_start_pressed():
    # Transition vers le niveau 1 (Voir Tome 4 pour le SceneManager)
    SceneManager.change_scene("res://levels/level_1.tscn")
Chapitre 3

Gérer le Menu Pause

Mettre le monde en pause, mais pas le menu.

Mettre un jeu en pause dans Godot est enfantin : get_tree().paused = true. Le problème, c'est que cela gèle absolument tout, y compris le menu de pause lui-même ! Vous ne pourriez plus cliquer sur "Reprendre". La solution réside dans le Process Mode.

Simulation Process Mode

JEU EN PAUSE

Process Mode: Always

Configuration de la Scène PauseMenu

1. Dans l'Inspecteur

Sélectionnez le nœud racine de votre scène de Pause (ex: CanvasLayer). Allez dans l'inspecteur sous Node > Process > Mode et changez Inherit pour Always.

Cela indique à Godot : "Même si l'arbre principal est en pause, continue d'exécuter ce nœud et ses enfants."

2. Dans le Script (Input)

L'action "ui_cancel" (Échap ou Start sur manette) doit déclencher la pause. 

func _input(event):
    if event.is_action_pressed("ui_cancel"):
        var is_paused = get_tree().paused
        get_tree().paused = !is_paused
        visible = !is_paused
        if visible:
            resume_btn.grab_focus()
Chapitre 4

Sauvegarder les Options

Persistance des données avec `ConfigFile`.

Si le joueur coupe la musique, il s'attend à ce qu'elle soit toujours coupée en relançant le jeu le lendemain. Pour sauvegarder des paramètres simples (Options, High Score, Touches assignées), Godot fournit une classe excellente : ConfigFile.

user://settings.cfg 
[Audio]
master_volume=1.0

[Video]
crt_shader=false

L'Autoload SettingsManager.gd

Créez un script global (Autoload) pour charger les paramètres au démarrage du jeu et les sauvegarder quand ils changent.

# settings_manager.gd (Autoload)
extends Node

const SAVE_PATH = "user://settings.cfg"
var config = ConfigFile.new()

# Variables stockant l'état en mémoire
var master_volume: float = 1.0
var use_crt: bool = true

func _ready():
    load_settings()

func save_settings():
    # Enregistre les valeurs dans l'objet ConfigFile
    config.set_value("Audio", "master_volume", master_volume)
    config.set_value("Video", "use_crt", use_crt)
    
    # Écrit le fichier physiquement sur le disque dur
    config.save(SAVE_PATH)

func load_settings():
    var err = config.load(SAVE_PATH)
    if err != OK:
        return # Le fichier n'existe pas encore (premier lancement)
        
    # Lit les valeurs (avec une valeur par défaut en 3ème argument si introuvable)
    master_volume = config.get_value("Audio", "master_volume", 1.0)
    use_crt = config.get_value("Video", "use_crt", true)
    
    # Appliquer les paramètres (ex: changer le volume du bus Master)
    var bus_idx = AudioServer.get_bus_index("Master")
    AudioServer.set_bus_volume_db(bus_idx, linear_to_db(master_volume))
Où se trouve "user://" ? Sous Windows, Godot sauvegarde généralement dans C:\Users\[Nom]\AppData\Roaming\Godot\app_userdata\[Nom du Projet]\. Cela garantit que les sauvegardes survivent même si vous déplacez le dossier du jeu.
