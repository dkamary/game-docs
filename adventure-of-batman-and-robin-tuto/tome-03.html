Le Système de Vagues (Spawner)

Générer le chaos en dehors de l'écran.

L'Illusion du Run & Gun

Dans Batman & Robin, le niveau 1 n'est pas rempli de 500 clowns pré-placés. Au lieu de cela, un système "surveille" la caméra et génère des ennemis juste à l'extérieur des bords de l'écran. Cela garantit une action constante sans surcharger la mémoire.

Implémentation (EnemySpawner.gd)

Créez un simple nœud Node2D appelé EnemySpawner, attachez-lui un Timer (Node enfant) réglé sur "Autostart". Placez ce Spawner en enfant de votre Camera2D (pour qu'il suive l'écran) ou calculez les bords de la caméra.

# enemy_spawner.gd
extends Node2D

@export var enemy_scene: PackedScene
@onready var camera = get_viewport().get_camera_2d() # Récupère la caméra active

# Fonction appelée par le signal 'timeout' du Timer enfant
func _on_spawn_timer_timeout():
    if enemy_scene == null or camera == null:
        return
        
    # 1. Instancier l'ennemi (Notre clown du Tome 2)
    var enemy = enemy_scene.instantiate()
    
    # 2. Déterminer de quel côté il spawn (Gauche ou Droite aléatoirement)
    var spawn_left = randi() % 2 == 0
    
    # 3. Calculer la position (Bord de l'écran + marge)
    var screen_width = get_viewport_rect().size.x
    var margin = 40 # Spawn 40 pixels en dehors de l'écran
    
    var spawn_x = 0
    if spawn_left:
        spawn_x = camera.global_position.x - (screen_width / 2) - margin
    else:
        spawn_x = camera.global_position.x + (screen_width / 2) + margin
        
    # Positionnement final. Note : on suppose que la scène a un sol défini.
    # Pour les ennemis volants, randomize() le 'y' ici.
    enemy.global_position = Vector2(spawn_x, camera.global_position.y - 50)
    
    # L'ajouter à la scène principale, PAS au spawner !
    get_tree().current_scene.add_child(enemy)
Object Pooling (Avancé) : Dans un jeu professionnel fini, au lieu de faire instantiate() et queue_free() sans arrêt (ce qui crée de petits lags), on crée un "Pool" de 20 ennemis au début du jeu, et on les déplace et les réactive hors écran. C'est l'Object Pooling.
Chapitre 2

L'Interface (HUD) & Signaux

Le Pattern Observer : Comment décupler proprement l'UI du Joueur.

L'erreur classique est de dire au joueur de mettre à jour l'UI : HUD.update_life(health). C'est mauvais car cela couple fortement le joueur à l'interface. Si vous supprimez le HUD pour un menu pause, le jeu plante. La solution ? Les Signaux Godot (Pattern Observer).

Simulation de Signal : health_changed

100%

1. Le Joueur Émetteur (Player.gd)

Le joueur ne connaît pas le HUD. Il se contente de crier "J'AI PERDU DE LA VIE !".

# player.gd
extends CharacterBody2D

# Définition du signal personnalisé
signal health_changed(new_health: int)

var health: int = 100

# Fonction appelée par la Hurtbox (Tome 1)
func take_damage(amount: int):
    health -= amount
    # On émet le signal avec la nouvelle valeur
    health_changed.emit(health)

2. L'UI Écouteuse (HUD.gd)

L'interface est placée dans un CanvasLayer. C'est elle qui connecte le signal.

# hud.gd (Attaché au CanvasLayer)
extends CanvasLayer

@onready var life_bar = $ProgressBar

func _ready():
    # Récupère le joueur dans la scène
    var player = get_tree().get_first_node_in_group("Player")
    if player:
        # Le HUD connecte le signal à sa propre fonction
        player.health_changed.connect(update_life_bar)

func update_life_bar(new_value: int):
    # On peut ajouter un Tween ici pour une animation fluide !
    life_bar.value = new_value
Le CanvasLayer : N'oubliez jamais que toute l'UI (Boutons, Score, Vie) doit être enfant d'un nœud CanvasLayer. Cela permet à l'UI de rester collée à l'écran indépendamment de la Camera2D qui suit Batman.

Hit Stop & Camera Shake.

Ce qui rend le jeu original si spectaculaire, ce sont les impacts. Quand un batarang touche, le jeu ne se contente pas de baisser la vie de l'ennemi. Il fait trembler l'écran (Camera Shake) et fige très brièvement le temps (Hit Stop).

L'Algorithme de Tremblement (Camera2D)

Plutôt que de faire un tremblement aléatoire brut (qui rend malade), on utilise une variable "Trauma" qui diminue avec le temps. Ajoutez ce script à votre Camera2D.

# camera_shake.gd
extends Camera2D

@export var decay: float = 0.8 # Vitesse de disparition du tremblement
@export var max_offset: Vector2 = Vector2(100, 75) # Intensité max

var trauma: float = 0.0 # De 0 à 1
var trauma_power: int = 2 # Carré du trauma pour plus d'impact au début

func _process(delta):
    if trauma > 0:
        trauma = max(trauma - decay * delta, 0)
        shake()
    else:
        offset = Vector2.ZERO # Retour à la normale

func shake():
    var amount = pow(trauma, trauma_power)
    # Génère un offset aléatoire entre -1 et 1, multiplié par l'intensité
    offset.x = max_offset.x * amount * randf_range(-1, 1)
    offset.y = max_offset.y * amount * randf_range(-1, 1)

# Fonction à appeler de l'extérieur (ex: quand un ennemi meurt)
func add_trauma(amount: float):
    trauma = min(trauma + amount, 1.0)
Hit Stop Rapide : Dans Godot 4, le Hit Stop (figer le jeu 50ms pour donner du poids à un coup) se fait très simplement : Engine.time_scale = 0.0. Lancez un Timer de 0.05s qui fait Engine.time_scale = 1.0 à son timeout. Effet garanti !

Le Boss du Niveau 1

Le Dirigeable du Joker (State Machine Avancée).

À la fin du niveau, le scrolling s'arrête. Le dirigeable du Joker apparaît en haut de l'écran. Un Boss classique suit des "Phases" (Patterns). Nous réutilisons le concept de State Machine du Tome 1, mais pour l'I.A.

🦇

Logique des Phases (Code Structure)

# boss_joker.gd (CharacterBody2D)
extends CharacterBody2D

enum Phase { ENTRANCE, BOMB_DROP, LASER, DEAD }
var current_phase = Phase.ENTRANCE
var health = 50

@onready var anim_player = $AnimationPlayer
@onready var timer = $PhaseTimer

func _process(delta):
    match current_phase:
        Phase.ENTRANCE:
            # Descend lentement dans l'écran
            velocity.y = 50
            if position.y > 100:
                velocity.y = 0
                change_phase(Phase.BOMB_DROP)
                
        Phase.BOMB_DROP:
            # Flotte de gauche à droite en suivant le joueur (avec un délai)
            # Les bombes sont gérées par le Timer
            float_around(delta)
            
        Phase.LASER:
            # S'arrête, charge un tir, tire !
            pass

func change_phase(new_phase):
    current_phase = new_phase
    if new_phase == Phase.BOMB_DROP:
        timer.start(1.5) # Lâche une bombe toutes les 1.5s
